# `git` gives you superpowers

A talk as part of a lesson of "Advanced Git" and using GitHub for collaboration to the 2025 cohort in the UCL/Imperial [CCMI CDT](https://ccmi-cdt.org/).

These slides borrow some diagrams and some structure from [Pro Git](https://git-scm.com/book/en/v2).
